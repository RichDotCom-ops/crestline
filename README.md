# Crestline
A clean savings app: add any amount, track your balance and history. Installable PWA with Supabase accounts.

## Setup
1. Create a Supabase project, run `schema.sql` in the SQL editor.
2. Put the project URL and anon key in `config.js`.
3. Add your site URL under Authentication > URL configuration.
4. Host on GitHub Pages (main / root).

Without keys the app still works and saves on the device.
