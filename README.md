# SafeSpend
Tells you how much you can spend today and still hit your savings goal. Manual inputs, no bank connections. Installable PWA.

## Setup
1. Create a Supabase project, run `schema.sql` in the SQL editor.
2. Put the project URL and anon key in `config.js`.
3. Authentication > URL configuration: add your site URL.
4. Host on GitHub Pages (Settings > Pages > main / root).

Without keys the app still works and saves on the device.
